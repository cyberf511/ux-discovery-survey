# تطبيق جمع بيانات UX Discovery — وثيقة التصميم

**التاريخ:** 2026-07-26
**الحالة:** معتمد

## الغرض

تطبيق ويب مؤقت (أسبوع واحد) لجمع إجابات مقابلات UX Discovery من أربع فئات من موظفي شركة حراسات: حارس، مشرف ميداني، مشرف عام، مدير شركة. الهدف استخراج المتطلبات الحقيقية قبل بناء شاشات تطبيق الحراسات.

## القرارات المعتمدة

| القرار | الاختيار |
|---|---|
| دخول المشارك | رابط مفتوح بدون كلمة مرور + اختيار الفئة + اسم اختياري |
| لوحة الإدارة | `/admin` محمية بكلمة مرور واحدة من متغير بيئة |
| التقنية | Go + SQLite (modernc.org/sqlite، بدون CGO) |
| الواجهة | سؤال واحد بالشاشة، حفظ تلقائي، RTL، مُحسَّنة للجوال |
| الحاوية | صورة Docker واحدة، هدف < 25MB |

## المعمارية

بايناري Go واحد يخدم الـ API والملفات الثابتة (مضمَّنة بـ `embed`). قاعدة SQLite بملف واحد على volume خارجي `./data/survey.db`.

```
[متصفح] ──HTTP──> [Go :8080] ──> [survey.db]
                      ├── /        واجهة المشارك
                      ├── /admin   لوحة الإدارة
                      └── /api/*   JSON
```

### الوحدات

- `internal/store` — كل الوصول لقاعدة البيانات. الواجهة الوحيدة للبيانات؛ لا SQL خارج هذه الحزمة.
- `internal/seed` — الأسئلة الأولية وتحميلها عند أول تشغيل.
- `internal/export` — تحويل الإجابات إلى CSV بترميز UTF-8 مع BOM.
- `internal/api` — معالجات HTTP للمشارك وللأدمن.
- `web/` — HTML/CSS/JS بدون خطوة بناء.

## نموذج البيانات

- **questions**: `id, text, kind, position, categories (JSON), required, options (JSON), section`
- **sessions**: `id (UUID), category, name, started_at, finished_at`
- **answers**: `session_id, question_id, value (JSON), answered_at` — مفتاح مركّب
- **settings**: `key, value` — يحوي `admin_password_hash` و `survey_open`

الفئات ثابتة: `guard, supervisor, area_manager, company_manager`.

## أنواع الأسئلة

`long_text`, `short_text`, `boolean`, `single_choice`, `multi_choice`, `ranking`, `scale_1_5`

الترتيب (`ranking`) يُنفَّذ بأسهم ↑↓ لا بالسحب — أسهل بيد واحدة على الجوال.

## تجربة المشارك

اختيار الفئة → اسم اختياري → سؤال واحد بالشاشة. الجلسة تُحفظ في `localStorage` فيقدر يغلق ويكمل لاحقًا. كل إجابة تُرسل فور الانتقال؛ لا يوجد زر إرسال نهائي. أزرار بارتفاع ≥ 56px وتباين عالٍ للاستخدام تحت الشمس.

## لوحة الإدارة

إدارة الأسئلة (إضافة/تعديل/حذف/إعادة ترتيب)، استيراد دفعة أسئلة، عرض النتائج، قفل الاستبيان، والتصدير.

## التصدير

- CSV شامل، و CSV لفئة واحدة مختارة.
- UTF-8 **مع BOM** حتى يعرض الإكسل العربي صحيحًا.
- صف لكل مشارك؛ أعمدة: المعرّف، الفئة، الاسم، وقت البداية، وقت الانتهاء، مكتملة؟، ثم عمود لكل سؤال.
- الترتيب يُصدَّر `1. أ | 2. ب`؛ الاختيار المتعدد بفاصل ` | `؛ صح/خطأ تُصدَّر `نعم`/`لا`.
- الجلسات غير المكتملة تُدرَج (عمود «مكتملة؟» = لا) لأن نقطة الانسحاب معلومة مفيدة.
- اسم الملف يحمل التاريخ. زر إضافي لتنزيل نسخة `survey.db`.

## معالجة الأخطاء

فشل حفظ الإجابة يُعرض للمستخدم مع إعادة محاولة تلقائية، والإجابة تبقى في `localStorage` حتى تُحفظ. الحفظ بعد قفل الاستبيان يُرفض بـ 409.

## الاختبار

اختبارات Go لطبقة `store` (إنشاء جلسة، حفظ إجابة، تحديث إجابة، رفض الحفظ بعد القفل) ولـ `export` (BOM، تنسيق الترتيب، الجلسات الناقصة).

## خارج النطاق (YAGNI)

لا تسجيل دخول للمشاركين، لا أدوار متعددة للأدمن، لا رسوم بيانية، لا إشعارات، لا دعم متعدد اللغات.
