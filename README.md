# استبيان UX Discovery — تطبيق مؤقت لجمع البيانات

تطبيق ويب خفيف لجمع إجابات مقابلات تصميم التجربة من أربع فئات: **حارس، مشرف ميداني، مشرف عام، مدير شركة**. مبني ليعمل أسبوعًا واحدًا ثم تُصدَّر بياناته ويُحذف.

- صورة Docker **10.8MB**، استهلاك ذاكرة **~3MB**
- بايناري Go واحد + قاعدة SQLite بملف واحد — بلا قاعدة بيانات خارجية ولا Node
- واجهة عربية RTL، سؤال واحد بالشاشة، حفظ تلقائي، تعمل بيد واحدة على الجوال
- **٥٩ سؤالًا محمّلة مسبقًا** — تشغّل وتبدأ الجمع فورًا

## التشغيل

```bash
cp .env.example .env
```

غيّر `ADMIN_PASSWORD` في `.env`، ثم:

```bash
docker compose up -d --build
```

- رابط المشاركين: `http://<عنوان-السيرفر>:8080/`
- لوحة الإدارة: `http://<عنوان-السيرفر>:8080/admin`

## لوحة الإدارة

| التبويب | الوظيفة |
|---|---|
| النتائج | كل الإجابات مجمّعة تحت كل سؤال، مع تصفية بالفئة |
| المشاركون | جدول بالمشاركين وعدد إجاباتهم وهل أكملوا، مع إمكانية الحذف |
| الأسئلة | إضافة/تعديل/حذف/إعادة ترتيب، واستيراد دفعة أسئلة نصية |
| تصدير البيانات | CSV شامل، CSV لفئة واحدة، ونسخة احتياطية من قاعدة البيانات |
| الإعدادات | قفل الاستبيان بعد انتهاء الأسبوع، ورابط المشاركين |

## التصدير

ملفات CSV بترميز **UTF-8 مع BOM**، فتفتح في إكسل بالعربي مباشرة بلا رموز مكسورة.

صف لكل مشارك، وأعمدة: المعرّف، الفئة، الاسم، وقت البداية، وقت الانتهاء، مكتملة؟، عدد الإجابات، ثم عمود لكل سؤال.

- أسئلة الترتيب تُصدَّر مرقّمة: `1. الحضور | 2. البلاغات`
- الاختيار المتعدد بفاصل ` | `، وصح/خطأ تُصدَّر `نعم`/`لا`
- الجلسات غير المكتملة مُدرَجة بعمود «مكتملة؟ = لا» — نقطة الانسحاب معلومة مفيدة

## أنواع الأسئلة

نص طويل · نص قصير · صح/خطأ · اختيار واحد · اختيار متعدد · ترتيب قائمة (بأسهم ↑↓) · مقياس ١–٥

## استيراد دفعة أسئلة

في تبويب الأسئلة، الصق نصًا كهذا:

```
## الحضور
كيف تسجل حضورك الآن؟
ما المشاكل التي تواجهها؟
```

كل سطر يصبح سؤالًا نصيًا طويلًا، والسطر الذي يبدأ بـ `##` يصبح عنوان قسم لما بعده.

## بعد انتهاء الأسبوع

1. من تبويب الإعدادات: **اقفل الاستبيان** (النتائج والتصدير تبقى متاحة).
2. من تبويب التصدير: نزّل ملفات CSV و**النسخة الاحتياطية** `survey.db`.
3. ثم:

```bash
docker compose down
```

مجلد `data/` يبقى على السيرفر — احذفه يدويًا فقط بعد التأكد من حفظ التصدير.

## متغيّرات البيئة

| المتغيّر | الافتراضي | الوصف |
|---|---|---|
| `ADMIN_PASSWORD` | — | **مطلوب.** كلمة مرور لوحة الإدارة |
| `DB_PATH` | `data/survey.db` | مسار ملف قاعدة البيانات |
| `ADDR` | `:8080` | عنوان الاستماع |

## بنية المشروع

```
main.go                  نقطة الدخول، الإقلاع والإيقاف المرتّب
internal/model/          الأنواع المشتركة (الأسئلة، الفئات، الجلسات)
internal/store/          كل الوصول لقاعدة البيانات — لا SQL خارجها
internal/seed/           الأسئلة الأولية الـ٥٩
internal/export/         تحويل الإجابات إلى CSV
internal/api/            معالجات HTTP (المشارك + الإدارة)
web/                     الواجهة — HTML/CSS/JS بلا خطوة بناء
```

## ملاحظة أمنية

الحماية كلمة مرور واحدة للوحة الإدارة فقط؛ رابط المشاركين مفتوح عمدًا لتسهيل التبنّي. لا ترفع التطبيق على إنترنت عام بدون HTTPS (ضعه خلف Nginx أو Cloudflare Tunnel)، ولا تجمع فيه بيانات حسّاسة.
